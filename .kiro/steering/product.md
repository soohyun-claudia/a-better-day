# 제품 개요

## 한 줄 요약
일하는 동안 모니터에 띄워 두고 흘끗 확인하는 개인 업무용 상시 대시보드.
내 일정, 할 일, 한 일, 하고 싶은 일을 한 화면에서 관리한다. (프로젝트 이름: A Better Day)

## 사용 환경과 전제
- 사용자는 나 한 명이다. 로그인, 권한, 다중 사용자 기능은 만들지 않는다.
- 내 Windows 11 PC에서 localhost로 실행한다. Chrome 앱 모드(주소창 없는 창) 또는 전체화면으로 계속 띄워 둔다.
- 기준 해상도는 1920×1080이다. 스크롤 없이 한 화면에 모두 보여야 한다.
- 조작은 최소화한다. 클릭 한 번으로 완료하고, Enter로 추가한다. 복잡한 편집은 모달로 분리한다.

## 핵심 개념
- **task**: "하고 싶은 일 → 할 일 → 하는 중 → 한 일"은 상태만 다른 같은 데이터다.
  - status: WISH(하고 싶은 일) / TODO(할 일) / DOING(하는 중) / DONE(한 일)
  - DOING은 동시에 최대 1개다. 상단 바의 "지금 집중할 일"로 쓴다.
  - WISH → TODO 승격은 버튼 한 번이다. ("이번 주" 버튼)
  - DONE으로 바뀔 때 done_at(완료 시각)을 기록한다.
- **event**: 날짜와 시간이 있는 일정. task와는 별도 데이터다.
  - MVP에서는 직접 입력한다. 외부 캘린더 연동은 나중 단계다.

## 데이터 모델 (개념)
- task: id, title, status, priority, category, due_date, due_time, done_at, created_at, updated_at, deleted_yn
- event: id, title, start_at, end_at, location, memo, deleted_yn
- 삭제는 논리 삭제다. deleted_yn으로 표시하고 화면과 집계에서는 제외한다.
- 마감은 due_date와 due_time으로 저장한다. "이번 주"는 이번 주 일요일 날짜로 저장한다. (자세한 표기 규칙은 tech.md)

## 화면 구성 (한 화면: 상단 바 / 3단 / 하단 바)
- **상단 바**: 날짜·요일과 시계(HH:mm), 지금 집중할 일 1개, 오늘 진행률(완료/전체 건수와 퍼센트 막대. 예: 3/7)
  - DOING이 없으면 "▶를 눌러 집중할 일을 골라 보세요" 안내를 보여준다.
- **왼쪽, 오늘 일정**: 위쪽에 "다음 일정 · HH:MM / 제목 / N분 후" 카드, 아래에 시간 비례 타임라인
  - 남은 일정이 없으면 "오늘 남은 일정이 없어요"를 보여준다.
  - 타임라인은 09:00~19:00 고정이고 1시간이 54px이다. 현재 시각선과 현재 시각 라벨을 표시한다.
  - 지난 일정은 흐리게, 진행 중인 일정은 강조한다.
- **가운데, 오늘 할 일**: TODO와 DOING 전부를 대상으로 최대 7개 표시, 나머지는 "N개는 숨김"
  - 각 행: 체크 버튼, 제목, 우선순위(높음/보통/낮음), 마감 표시, ▶(하는 중으로 변경) 버튼
  - DOING 행은 파란 강조와 "진행 중" 표시를 하고 ▶는 없다.
  - 하단에 빠른 추가 입력창(Enter로 추가)이 있다.
- **오른쪽 위, 한 일**: 오늘 완료한 항목을 최근 순으로 최대 4개, 완료 시각과 함께 표시한다. 없으면 "아직 끝낸 일이 없어요" 안내를 보여준다.
- **오른쪽 아래, 하고 싶은 일**: 카테고리 태그(#학습), 4개 표시, 나머지는 "외 N개는 접어 두었어요", 총 개수 표시. "이번 주" 버튼 한 번으로 할 일로 승격한다.
- **하단 바**: 이번 주(월~일) 완료 건수, 요일별 완료 막대(오늘 강조, 아직 안 온 요일은 비움), 내일 일정 미리보기(3개)

## 동작 규칙 (프로토타입 기준)
- 정렬(오늘 할 일): DOING 먼저, 그다음 우선순위 높음 → 보통 → 낮음, 같으면 마감이 빠른 순(마감 없음은 뒤), 그래도 같으면 먼저 만든 순.
- 체크: DONE으로 바꾸고 완료 시각을 기록한다.
- ▶: 해당 task를 DOING으로 바꾸고, 기존 DOING은 TODO로 되돌린다.
- 승격: WISH → TODO, 우선순위는 보통, 마감은 "이번 주"로 둔다.
- 빠른 추가: TODO로 만들고, 우선순위는 보통, 마감은 "오늘 중"으로 둔다.
- 마감 표시: 시각이 있으면 "15:00 마감"으로 보여주고, 2시간 이내면 "· 1시간 40분 남음", 지나면 "· N분 지남"을 붙인다. 시각이 없는 마감은 "내일 마감", "11/6 마감", "이번 주 마감", "오늘 중", "마감 없음" 같은 문구로 보여준다.
- 진행률: 오늘 완료 수 / (남은 TODO·DOING 수 + 오늘 완료 수)
- 빠른 추가: 공백만 있는 입력은 추가하지 않는다. 추가에 성공하면 입력창을 비운다.
- 긴급(주황) 판정은 시각이 있는 마감에만 적용한다. "내일 마감", "이번 주 마감" 같은 날짜·기간 마감은 긴급으로 보지 않는다.
- 다음 일정이 15분 이내로 다가오면 "다음 일정" 카드와 타임라인의 해당 일정 카드 테두리를 주황으로 바꾼다. 진행 중인 일정은 밝은 테두리로 강조한다.
- 현재 시각선: 09:00 이전이면 타임라인 맨 위, 19:00 이후면 맨 아래에 고정한다.
- 요일별 막대 높이는 이번 주 최대 완료 수(최소 8건 기준) 대비 비율로 정한다. 0건인 요일은 얇은 회색 막대로 두고 숫자를 숨긴다. 오늘 요일 라벨은 반전해서 강조한다.
- 한 일, 이번 주 완료 수, 요일별 완료 수는 모두 done_at 기준으로 집계한다. 화면에 쓸 집계 API가 필요하다.
- 하고 싶은 일의 정렬 기준은 프로토타입에 없다. 만든 순을 기본으로 한다.

## 화면 요소 체크리스트 (MVP 완료 기준)
프로토타입의 아래 요소가 하나도 빠지지 않고 구현되어야 MVP가 끝난 것이다.
- [ ] 상단 바: 시계(HH:mm), 날짜·요일·연도, 지금 집중할 일(파란 점 + 제목 / 없을 때 안내), 오늘 진행률(퍼센트 막대, 완료/전체 숫자)
- [ ] 오늘 일정: 건수 표시와 + 버튼(일정 추가), 다음 일정 카드(시각, 제목, N분 후), 시간 눈금(09~19시), 일정 카드, 현재 시각선과 시각 라벨, 지난 일정 흐림, 진행 중 일정 강조
- [ ] 오늘 할 일: "남은 N개 · M개는 숨김" 표시, 행(체크 버튼, 제목, 진행 중 표시, 우선순위, 마감, ▶ 버튼), 빠른 추가 입력창(Enter 힌트 포함)
- [ ] 한 일: "N건 완료" 표시, 행(체크 아이콘, 제목, 완료 시각), 빈 상태 문구
- [ ] 하고 싶은 일: "총 N개" 표시와 + 버튼(추가), 행(제목, #카테고리, "이번 주" 승격 버튼), "외 N개는 접어 두었어요"
- [ ] 하단 바: 이번 주 완료 건수, 요일별 완료(주간 날짜 범위 표시, 월~일 7개 막대, 오늘 강조), 내일 일정(날짜·요일 표시, 최대 3개)
- [ ] 편집 기능 전체 (아래 섹션)

## 편집 기능 (MVP 필수, 프로토타입에는 화면이 없음)
- 오늘 할 일: 제목, 우선순위, 마감을 수정할 수 있고 삭제할 수 있다.
- 하고 싶은 일: 추가, 제목·카테고리 수정, 삭제, 카테고리 지정이 모두 가능하다.
- 우선순위 지정: task의 우선순위(높음/보통/낮음)를 사용자가 직접 지정할 수 있다. 빠른 추가는 Enter 한 번 흐름을 유지하므로 기본값(보통)으로 만들고, 이후 수정에서 바꾼다.
- 일정(event): 직접 추가, 수정, 삭제할 수 있다. (제목, 시작·종료 시각, 장소, 메모)
- 편집은 모달로 한다. 기존 화면 배치는 바꾸지 않고, 모달은 프로토타입의 스타일(다크, 큰 글씨, 색 규칙)을 따른다.
- 삭제는 모달 안에서 한 번 더 확인한 뒤 실행한다.
- 모달 디자인은 프로토타입 캔버스의 모달 3종(할 일 수정, 하고 싶은 일 추가·수정, 일정 추가·수정)을 따른다. docs/ 의 모달 캡처 이미지가 기준이다.
- 할 일 수정 필드: 제목, 우선순위(높음/보통/낮음), 마감(없음 / 오늘 중 / 내일 / 이번 주 / 날짜·시각 지정, 시각은 비워 둘 수 있음)
- 하고 싶은 일 필드: 제목, 카테고리(기존 카테고리 선택 또는 새로 입력), 우선순위("이번 주"로 할 일이 되면 이 우선순위를 적용)
- 일정 필드: 제목, 날짜, 시작·종료 시각(종료는 시작보다 늦어야 함), 장소, 메모
- 여는 방식: 행의 제목 영역을 누르면 수정 모달, 하고 싶은 일·오늘 일정 헤더의 + 버튼은 추가 모달이다. 체크, ▶, "이번 주" 버튼은 지금처럼 바로 동작한다.
- 빨강(#FF6B6B)은 삭제와 입력 오류에만 쓴다.

## 디자인 원칙
- 다크 테마, 큰 글씨. 떨어져서도 읽혀야 한다.
- 색은 의미가 있을 때만 쓴다.
  - 주황: 긴급 (마감까지 2시간 이내이거나 지남, 우선순위 높음, 시작 15분 전 이내의 다음 일정)
  - 파랑: 하는 중(DOING)
  - 초록: 완료
- 시계, 현재 시각선, 남은 시간은 30~60초마다 자동 갱신한다.
- 화면 디자인 기준은 docs/ 폴더의 프로토타입 캡처 이미지다.

## 단계별 범위
1. MVP: 위 화면 전체, task 4상태 관리, 일정 직접 입력
2. 다음: 주간 요약 강화, 반복 일정·반복 할 일
3. 나중에: Google Calendar 등 외부 일정 연동, 여러 기기에서 쓰기 위한 AWS 배포(인증 포함)

## 아직 정해지지 않은 것 (임의로 정하지 말고 나에게 물어볼 것)
- 하고 싶은 일의 카테고리 목록 (프로토타입 샘플은 학습, 운동, 사이드 프로젝트)
- priority 값 체계: 프로토타입은 높음/보통/낮음 3단계다. 이대로 확정할지 확인한다.
- "오늘 할 일"의 범위: 프로토타입은 마감일과 무관하게 TODO·DOING 전부를 보여준다. 이대로 할지 확인한다.
- 타임라인 표시 시간대(09:00~19:00) 밖의 일정을 어떻게 보여줄지
